# Программа, которая будет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять фильтровать.

1. ### Установка
2. Установите зависимости, указанные в `pyproject.toml`

### Описание
- **`BaseApi`** - основной класс для разработки API-классов, таких как `HeadHunterApi`.
- **`HeadHunterApi`** - предназначен для выполнения запросов на получение вакансий с платформы hh.ru и сохранения полученных данных в файл формата JSON.
- **`BaseJsonSaver`** - шаблонный класс для создания классов, отвечающих за сохранение данных, таких как `JsonSaver`.
- **`JsonSaver`** - предоставляет функциональность для сохранения, добавления и удаления вакансий в/из файла в формате JSON.
- **`Vacancy`** - класс, который используется для создания объектов вакансий с такими атрибутами, как:
  - `name` (название)
  - `url` (ссылка)
  - `salary` (зарплата)
  - `snippet` (краткое описание).

Модуль `user_interaction` включает функции для взаимодействия с классами и осуществления фильтрации вакансий. Взаимодействие всех классов и функций с пользователем реализовано в модуле `main.py`.

## Тестирование

Все модули и классы тестируются в пакете `tests`.
